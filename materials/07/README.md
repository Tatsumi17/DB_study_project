# 独立した移行試験資料
6行。JSONをUTF-8テキストで開く。初期Excelの人物・顧客とは別の人工データ。学習者自身のスキーマへ対応させる。

source_rowはこの資料の一意な入力行ID。external_customer_idは外部システムが同一性を保証した会社ID（値がある場合）。同じIDのM001/M002は同じ会社・同じ窓口の訂正。updated_atはこの独立資料での情報更新日で、新しいものを採用して旧値の扱いを記録する。このルールを初期Excelへ無条件に適用しない。
EXT-001とEXT-003は同名の別会社。M006はID未確認でM003との同一性不明。M005は不正メール/日付と未対応担当を含む。推測で修正せず保留/拒否と理由を報告する。
SALES-A/Bは独立試験用担当コード。学習者が試験アカウントと明示対応させる。UNKNOWNは対応なし。実際の佐藤/高橋へ自動対応しない。
元Excel19行とこの6行はそれぞれ別のバッチとして照合する。大容量の性能試験ではなく品質・再実行・追跡の演習。必要なら自作人工データを増量し、条件と件数を記録する。
